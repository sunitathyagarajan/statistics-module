# statistics-module

A module teaching the basics of statistics to Quant lab students.

**Live site:** https://sunitathyagarajan.github.io/statistics-module/

## What's in it

- Key terms for quantitative analytical chemistry (mean, median, variance, standard deviation, uncertainty, confidence intervals, LOD/LOQ and more), each with a real-world example
- Three medical and three chemistry worked examples (teaching data)
- Two real cases built from published data where misreading the data changed the outcome: the Challenger O-rings and the Vioxx VIGOR trial
- Interactive data explorer, normal-curve and confidence-interval simulator, and propagation-of-uncertainty calculator
- The Q test, F test and t test (mean vs. known value, two means, paired), each with a playground and a random problem generator (1–5 problems)
- Critical value tables for t, F and Q
- A significant figures page: the counting and calculation rules, a digit counter, and 20 practice problems (10 calculations, 5 from a titration case study, 5 with reflection questions)

## Files

- `index.html`: the module itself, one self-contained page
- `sigfigs.html`: significant figures rules and practice problems
- `references.html`: sources for the definitions, tests, real cases and practice problems

To change the site, edit these files and push to `main`; GitHub Pages republishes automatically.
